메모장에서 붙여넣기

한 줄에 하나씩 적어 주세요. 단어 : 뜻, 단어 - 뜻, 뜻 없이 단어만, 해석 연습할 긴 문장 모두 돼요.

영어 단어 하나짜리는 무료 영어사전에서 영어 풀이와 예문을 자동으로 채워요. 한국어 뜻과 CELPIP 예문은 단어장 탭에서 ‘수정’으로 언제든 고칠 수 있어요.
백업

단어와 복습 기록은 이 폰 안에만 저장돼요. 가끔 백업 파일을 저장해 두면 폰을 바꿔도 그대로 옮길 수 있어요.

아이폰 홈 화면에 설치
  1. 사파리에서 이 주소를 열어요.
  2. 아래쪽 공유 버튼(네모에 위쪽 화살표)을 눌러요.
  3. ‘홈 화면에 추가’를 누르면 앱 아이콘이 생겨요.
매일 아침 9시에 열기
  1. 단축어 앱 → 자동화 → 새로운 자동화 → ‘특정 시간’ 9:00, 매일.
  2. ‘즉시 실행’을 고르고, 동작으로 ‘URL 열기’에 이 앱 주소를 넣어요.
  3. 매일 9시에 알림이 오고, 누르면 바로 오늘 복습이 열려요.
